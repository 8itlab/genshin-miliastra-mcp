# 预设状态：机关物件自带的动作（宝箱开合、拉杆、门）

来源：官方综合指南“预设状态”一页的说法，加上 48 份官方教学存档里实际写的数据（`scripts/dev/presets.mjs` 汇总）。2026-10-10 整理。工具侧见 `scene_add_prefab` 和 `scene_search_assets`；宝箱、拉杆已上机验证（`examples/checks`、`examples/hop`）；2026-10-11 又上机筛了一批官方样例没用过的机关，见文末。

## 是什么

每个动态物件都有“预设状态”：平台预先做好的表现动画，按“状态编号 + 状态值”切换。创作者不能自己做新的状态，只能用物件自带的。官方样例里它是“表现变化”最常用的手段之一（11 份样例、25 个节点在用），和“销毁了再创建另一个元件”并列。

典型用法（都来自官方样例）：

- 宝箱：选项卡选中 → 【设置预设状态】值 1（箱盖打开）→ 关掉选项。
- 拉杆：选项卡选中 → 值 1（扳下），再选一次 → 值 0（复位）；同时去开门、发信号、点火。
- 木门：值 1 开、值 0 关。
- 弹弹菇：角色进入触发器 → 值 1（压扁），离开 → 值 0。

## 在图里怎么写

```ts
f.setPresetStatus(entity, 100010060n, 1n)      // 状态编号、状态值
f.getPresetStatus(entity, 100010060n)          // 读当前值
.on('whenPresetStatusChanges',(evt,f)=>{ evt.presetStatusId; evt.preChangeValue; evt.postChangeValue })
```

填了物件没有的状态值，不会切换，也不报错。

## 状态编号从哪来

存档里，机关元件的模型组件（基础组件 2）登记着它的状态编号和初始值：`{1: 2, 12: {2: {1: 状态编号, 2: 初始值}}}`，初始值为 0 时省略；没有预设状态的物件这里是空的。`scene_add_prefab` 用下表里的资产造元件时会照这个写，返回值里的 `presetStatus.statusId` 就是图里要填的编号；`scene_search_assets` 的结果里这些资产带 `presetStatus` 字段。

规律：这批“交互机关”（资产编号 10005xxx）的状态编号 =（资产编号 − 4000）× 10。但有例外（同一套模型的几个变体共用一个编号），所以工具只认下表里被官方样例确认过的，不按规律去猜。

## 对做游戏的意义

之前的王国样例里，“门打开”“墙升起”是靠运动器或者销毁重建做的，宝箱和拉杆这类现成的机关一个都没用。平台的做法是：要一个能开的箱子、能扳的拉杆、能开的门，直接用“交互机关”组里的物件，加选项卡或触发器，事件里设预设状态。

## 2026-10-11 上机筛出来的一批（`examples/presets`）

办法：`scene_add_prefab` 的 `presetStatusId` 给元件登记“(物件编号 − 4000) × 10”这个编号，然后试玩。编号不成立时编辑器的试玩校验不让进，并点名元件；一个小脚本一圈一圈把被点名的去掉，直到校验通过，最后一圈就是正式的一轮：每个物件先设 1 再设 2，各读回一次。

- **32 个里 27 个有这个编号**，值 1 都被接受（读回 1，收到一次【预设状态变化时】）：石质机关 10005002 / 10005017 / 10005057 / 10005086、弹弹菇 10005004、木质风车 10005010、发条炸弹 10005012、金属牢笼 10005013、积木平台 10005014、积木按钮 10005016、金属舞台灯 10005021、金属发条机关 10005029、金属钟 10005032、木质地板门 10005035、地脉镇石 10005037、金属拳靶 10005052、金属治疗球 10005053、轨道停止器 10005058、木质地门 10005063、金属机关 10005079 / 10005080、金属惊喜盒 10005083、金属开关 10005084、钟 10005087、弩机 10005091、稻草人 10005094、笼子 10005096。
- **值 2 只有两个有**：金属拳靶 10005052（靶子升到最高）、弩机 10005091。其余 25 个设 2 之后读回来还是 1：物件没有的值不会被接受。
- **截图里看得出变化的**：木质地板门、木质地门设 1 会翻开（可以当活板门用）；金属惊喜盒弹开；地脉镇石亮起；轨道停止器的挡板升起；金属钟摆动；金属拳靶升起。其余的在 15 米镜头下看不出变化，要拉近再看。
- **5 个没有这个编号**（校验不通过）：冰元素方碑 10005023、大炮 10005093、赠礼箱 10005142、木质牢笼 10006001、捕兽夹 10006002。它们可能用别的编号，没再试。

这些都进了 `src/scene/preset-status.json`，`scene_search_assets` 的结果里会带出来。
