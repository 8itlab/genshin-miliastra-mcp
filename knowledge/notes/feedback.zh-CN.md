# 反馈：让关卡不像半成品

2026-10-11 整理。来源：官方教程“4.1.2《农场乱斗》操作提示与反馈”和“2.5 特效”两课（用自己的话归纳），加上我们在 `examples/kingdom5`、`examples/listen` 里上机实测过的做法。

为什么要有这一页：10 月 11 日用户亲手玩了我们做的三个游戏，评价是“缺点儿什么，还是一股 demo 味儿”。那三个游戏是按“脚本跑得通”验收的：规则都对，但玩家做了一件事之后，屏幕上和耳朵里几乎什么都没发生。这一页说的是补上这一层的做法。

## 官方是怎么做的（农场乱斗这一课）

| 要表达什么 | 官方做法 |
|---|---|
| 这个东西可以拿 | 给它加一个一直转的基础运动器，再挂一个循环特效 |
| 我现在拿着什么 | 另做一个同模型的装饰元件，带跟随运动器，吸到角色的手上（挂接点 `RHand`）；换工具时销毁旧的、创建新的 |
| 我采到了东西 | 每采一个，创建一个小装饰跟在角色身后，位置各错开一点，采得多就叠成一串；交货时按记下的实体列表逐个销毁 |
| 这块地现在能操作 | 走进去时给这块地挂一个白色方框的循环特效，走出去时清掉 |
| 数量、分数 | 界面文本框（要奇匠 Lv.2 才显示自定义文字） |

共同点：每一个状态变化都有一个看得见的东西跟着变，而且尽量用“东西本身”来表达（跟着的果子、手里的工具），不靠文字。

## 我们能用的手段（都上机对过）

| 手段 | 怎么用 | 查编号 |
|---|---|---|
| 一次性的特效 | `f.playTimedEffects(编号, 实体, 'GI_RootNode', true, false, 偏移, [0,0,0], 缩放, true)`，最后一个参数是连特效自带的声音一起放 | `effect_catalog {query, kind:"timed"}` |
| 一直在的特效 | `f.mountLoopingSpecialEffect(...)` 挂上，`f.clearSpecialEffectsBasedOnSpecialEffectAssets(实体, 编号)` 清掉 | `effect_catalog {query, kind:"looping"}` |
| 音效 | `f.playerPlaysOneShot2dSoundEffect(玩家, 编号n, 音量n, 速度)`，不需要给谁加组件 | `sound_catalog` |
| 背景音乐 | `f.modifyPlayerBackgroundMusic(玩家, 编号n, 0, 这首的秒数, 音量n, true, 0, 1, true)`，随时可以换 | `music_catalog` |
| 屏幕上的条和钟 | 进度条跟着玩家的变量走；计时器控件显示全局计时器 | `scene_add_progress_bar`、`scene_add_timer_display` |
| 屏幕上的图 | 平台自带的图，或一块带颜色、可半透明的矩形（底板、色块）；先加的在下面 | `scene_add_image`，能用的图在 `scene_list_interface` 的 `knownImages` |
| 跟着角色的东西 | 元件带跟随运动器，`f.switchFollowMotionDeviceTargetByEntity(元件, 角色, '', 偏移, ...)` | `scene_add_components {follow}` |
| 天色 | 两套环境配置之间切换 | `scene_add_environment` |

循环特效里有几样专门用来“指给人看”的：黄色提示标记（10001085，一组向下的箭头）、指示箭头（10004094）、白色/红色矩形提示（10001078、10001079）、黄色光柱（104），还有五个表情符号：疑惑（10004184，一个问号）、高兴（10004185）、沮丧（10004186）、担心（10004182）、惊讶（10004183）。

## 该给哪些时刻配反馈

做完规则之后，把玩家会经历的时刻列一遍，每一个都要有声音和画面。`examples/kingdom5/kg5_feel.json` 是一张现成的表，下面是它覆盖的时刻：

| 时刻 | 王国第五版的做法 |
|---|---|
| 捡到东西 | 提示音 + 角色身上的拾取特效 + 钱袋的条涨一格 |
| 买成了 | 确认音 + 站点上的闪光；买来的人出现时脚下一团烟尘 |
| 买不了（钱不够、缺前提） | 错误音 + 站点上方冒一个问号，一秒半后消失 |
| 现在能买 | 站点上方一直挂着黄色提示标记，买不起了就摘掉 |
| 要花多少 | 站点上方一排小金币，几枚就是几块钱（见下面“没有文字”） |
| 危险要来了 | 入夜前 8 秒敲钟；这时如果没有墙，筑墙点闪红色预警 |
| 局面变了 | 入夜：天色变暗、灯亮、换成战斗音乐；天亮：鸡叫、换回白天的音乐 |
| 打中、打死 | 箭是一个挂着“普通箭矢”特效、追着目标飞的元件；命中有命中特效和声音 |
| 我方挨打 | 墙被撞：烟尘 + 撞击声，墙的条往下掉；墙倒：碎石特效 + 重的一声 |
| 被偷、快输了 | 被偷：角色身上红色受击 + 扣血音，钱袋的条掉；王冠被抢之前有两秒半的预警圈和锁定音，跑开就能躲掉 |
| 赢、输 | 赢：烟花 + 结束音 + 换音乐，四秒后才结算；输：头顶的王冠飞到怪身上，两秒后结算 |

## 没有文字的时候（奇匠 Lv.1）

账号是奇匠 Lv.1 时，自定义文本框不显示，**选项卡的选项文字也不显示，只有图标**（计时器的数字、进度条的百分比、商店和背包界面上的字是平台自己的，正常显示）。所以：

- 价格用东西的个数表示：一排小金币。
- “能不能做”用标记表示：挂着黄色箭头就是现在能买。
- “为什么不行”用问号表示。
- 数量用进度条表示，上限取 10 的倍数，百分比读起来就是个数（钱袋上限 10，一枚币 10%）。
- 一个站点做什么，靠它的样子和站在旁边的人：营地旁边站着待招的流民，弓铺旁边立着箭靶。
- 屏幕上的图片控件在 Lv.1 也显示（2026-10-13 上机看过）：进度条旁边放一个图标说明这条是什么（水果是吃的、宝箱是战利品、剑盾是战斗），条和钟后面垫一块半透明的黑底板让它们从画面里分出来，一排圆点当“还剩几条命”（少一条命就关掉一个：`f.modifyUiControlStatusWithinTheInterfaceLayout(玩家, 控件编号, UIControlGroupStatus.Off)`，上机验过，范例 `examples/images/images_lives.json`）。
- 数字也能显示：进度条的 `shows: "value"` 直接写出当前值（钱袋里 7 枚就显示 7.0），不需要自定义文本框；圆环形的进度条适合做冷却和蓄力。能用的图有一千六百来张（`image_catalog` 按分类给出图库的照片，每张图下面是编号）：心形、钥匙、宝箱、药瓶、武器、元素、旗子、星星、皇冠、箭头、对勾和叉都有，照着图挑编号。

## 怎么知道声音真的响了

脚本试玩时没有人在听。`playtest_start {recordAudio:true}` 会把这一局的声音录下来，`playtest_status` 的 `audio` 里有录音文件、每一秒的响度和每个声音开始的时刻。日志里打印行的秒数比真实时间慢约 1%，起点也晚约 0.8 秒，对时间时按“打印之后一两秒内有一个起音”来对。

音效的名字只说用途，不说听起来什么样。`examples/listen` 每三秒放一条候选音效并录音，`scripts/dev/measure_sounds.py` 量出每条的时长、响度和明亮程度；量过的 73 条在 `sound_catalog` 的结果里带着 `seconds` 和 `brightHz`。好不好听还是要人来听：录音文件就在试玩目录里。
