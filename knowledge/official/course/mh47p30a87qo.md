# 客户端脚本——驱动控件交互，实现轻量2D玩法

## 功能示例-1：制作一个收集圆圈玩法

### 1.概念简述

**客户端脚本：** 挂载在“客户端控件容器”上的 Lua 脚本，可在本地读取和更新客户端控件，监听光标/键盘事件，并通过逐帧更新实现持续变化的界面和玩法逻辑。

**客户端控件容器：** 客户端控件与客户端脚本的运行载体。脚本通过容器节点获取编辑器预置的子控件，并控制其显示、位置、文本与可交互状态。

 _**例如，点击收集、UI 动画、2D射击等表现型玩法，均可优先通过客户端控件和 Lua 脚本实现。_

### 2.教学内容

**功能效果：** 制作一个2D收集圆圈玩法，屏幕中出现圆圈，点击收集圆圈后获得分数

①**游戏开始/初始化** ：在脚本中，先通过 `script.object` 获取脚本挂载的容器节点，再按照编辑器中配置的名称获取圆圈容器、圆圈点击区域和分数文本等。为了让光标检测区域正常接收光标事件，还需要开启容器节点的 `showCursor`。

要做的功能| 对应的脚本逻辑  
---|---  
获取当前脚本挂载的容器节点| 使用 `script.object`  
获取当前界面和游戏状态| `local Game = {参数=xx}`设置对应参数值  
获取编辑器中预置的子控件| 使用 `GetChild("控件名称")` 按层级查找对应控件  
获取画布尺寸| 使用 `game.GetUICanvasSize()` 获取 UI 画布宽高  
获取圆圈大小| 使用圆圈容器或圆圈图片的 `GetSizeDelta()` 获取宽高  
让光标检测区域能够接收点击| 将容器节点的 `showCursor` 设置为 `true`  
  
**代码示例：**
    
    
    --获取当前脚本绑定的对象，后续通过 this 操作当前 UI 或者脚本节点。
    local this = script.object  
    
    --定义游戏状态表，用来保存分数、是否运行、是否一开始，以及画布尺寸等运行数据
    local Game = {				
        score = 0,
        running = false,
        started = false,
        startAttempts = 0,
        startRetryBudget = 60,
        canvasWidth = 0,
        canvasHeight = 0,
    }							
    
    --获取界面中的子节点引用，方便后续控制背景、圆圈区域、圆圈图片和文本分数
    local background = this:GetChild("背景")		
    local circleRoot = this:GetChild("圆圈容器")
    local circleArea = circleRoot:GetChild("圆圈点击区域")
    local circleImage = circleRoot:GetChild("圆圈图片")
    local scoreText = this:GetChild("分数文本")
    
    --读取 UI 画布的宽高，用于后续布局、定位或边界计算
    local canvasWidth, canvasHeight = game.GetUICanvasSize()
    
    --定义圆圈的尺寸常量，并根据直径计算半径，便于统一管理碰撞范围或显示大小
    local CIRCLE_SIZE = 112
    local CIRCLE_RADIUS = CIRCLE_SIZE / 2
    
    --显示鼠标光标，通常用于需要鼠标点击交互的 UI 场景
    this.showCursor = true

②**圆圈生成事件：** 圆圈出现的位置不能超过画布边界，否则会出现圆圈只显示一部分、甚至完全出现在屏幕外的情况，需要根据画布宽高与圆圈宽高，计算圆圈能够出现的安全范围。

要做的功能| 对应的脚本逻辑  
---|---  
获取圆圈占用范围| 使用 `GetSizeDelta()` 获取圆圈容器或图片控件的宽高  
防止圆圈生成到屏幕外| 用画布半宽/半高减去圆圈半宽/半高，得到随机坐标最大范围  
生成随机位置| 使用 `math.random()` 在安全范围内生成 X、Y 坐标  
让视觉与点击区域一起移动| 对圆圈容器调用 `SetAnchoredPosition(x, y)`  
  
**代码示例：**
    
    
    --函数作用：根据画布大小和圆圈尺寸，随机生成一个位置并将圆圈移动到该位置。
    local function spawnCircle()
    	--读取圆圈尺寸，获取“圆圈容器”的宽高
        local circleWidth, circleHeight = circleRoot:GetSizeDelta()
    
    	--计算可移动范围，确保圆圈不会跑出屏幕边界
        local maxX = math.max(Game.canvasWidth * 0.5 - circleWidth * 0.5, 0)
        local maxY = math.max(Game.canvasHeight * 0.5 - circleHeight * 0.5, 0)
    
    	--生成随机坐标
        local x = (math.random() * 2 - 1) * maxX
        local y = (math.random() * 2 - 1) * maxY
    
    	--移动“圆圈容器”到新位置
        circleRoot:SetAnchoredPosition(x, y)
        return true
    end

③**处理点击事件和加分：** 在圆圈点击区域上监听【光标点击】事件。成功点击圆圈后，先增加分数并更新文本；如果尚未达到目标分数，就将圆圈移动到新的随机位置。

要做的功能| 对应的脚本逻辑  
---|---  
分数增加| 将 `Game.score`的数值增加一点  
判断游戏是否正在运行| `Game.running`的值为`True`时标识游戏正在运行  
刷新分数文本| 修改文本框的 `text` 字段，例如“分数：”..Game.score  
判断分数是否达标| 对比`Game.score`和`Game.scoreTarget`的大小，目标达成后发送信号  
点击后出现新圆圈| 调用 `spawnCircle()`  
  
**代码示例：**
    
    
    --函数作用：把当前分数更新到 UI 文本中
    local function updateScore()
        scoreText.text = "分数：" .. tostring(Game.score)
    end
    
    --函数作用：处理点击事件
    local function onCircleClick(_data)
    	--检查游戏是否正在运行，如果没有运行，则不处理点击
        if not Game.running then
            return
        end
    
    	--禁用点击检测，更新分数数值和显示
        circleArea.raycastTarget = false
        Game.score = Game.score + 1
        updateScore()
    
    	--判断是否达到游戏目标
        if Game.score >= Game.scoreTarget then
            Game.running = false
            game.ServerSignal("success"):SendSignal()
            return
        end
    
    	--重复调用生成圆圈函数，生成新的圆圈位置
        spawnCircle()
    
    	--重新启用点击检测，允许下一次点击
        circleArea.raycastTarget = true
    end
