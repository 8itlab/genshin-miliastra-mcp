# 概念介绍/其它概念/环境配置

(来源：原神千星奇域·综合指南，页面 ID mhdznsie9up8)

# 一、环境配置的定义

环境配置包含一系列环境表现相关参数，可用于丰富场景中各要素的表现

环境配置需要预先定义，并应用于各玩家的客户端

# 二、环境配置的编辑

切换至地形编辑页签，可在左侧选择环境配置。

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhdznsie9up8/172df58d-bc47-45fc-919d-53270638c0cf.png)

点击【新建环境】并【确认创建】即可新建一份环境配置

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhdznsie9up8/6900ed15-693d-4067-b68d-18823586f564.png)

## 1.环境配置

### (1)生效目标

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhdznsie9up8/031ca4a0-51c3-4b75-b12b-ca22af1b07a4.png)

可以选择该份环境配置对哪些玩家生效

### (2)背景预设

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhdznsie9up8/e1664713-7e94-4673-b8ee-9bcd6b4c32fa.png)

可选择一份背景预设，决定场景表现的大致风格

 _随时间自动切换_ ：如果启用，则场景中背景相关的要素都会随时间变换。如果不启用，则不会随着时间变换，而是保持当前配置的固定值

 _设定时间点_ ：表示当前的背景设置保存在哪个时间点，不同的时间点可以保存不同的背景设置，并在可动态变化时随着环境时间的变化而变化

 _动态预览_ ：启用【随时间自动切换】时，可以打开动态预览

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhdznsie9up8/2d8cb40d-8133-4367-8c7e-97cf36ff8494.png)

 _参考时间点列表_ ：可以选择任意时间点查看其对应的背景设置

 _天气配置_ ：可以选择一份提前配置好的天气配置与当前时间点关联

 _每秒流逝时间(分钟)_ ：开启预览时，现实时间每经过一秒游戏内时间会经过多久。24为提瓦特时间，可配置区间为[0,60]

_当前预览时间_ ：表示当前正在预览的时间点

 _预览_ ：点击【预览】则环境时间会按照设置的【每秒流逝时间】进行流逝，以此来动态查看24小时内的环境变化

### (3)背景设置

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhdznsie9up8/c55fcfd1-9c11-4fc8-9eb4-74ad3d71faec.png)

 _背景旋转_ ：调整背景的角度

 _直射角_ ：环境主光源的直射角度

 _强度_ ：环境主光源的强度，数值越高越亮

 _模糊程度_ ：环境主光源的模糊度，数值越高越模糊

 _受光颜色_ ：环境的受光颜色

 _滤镜风格_ ：在相机层增加滤镜效果

 _光晕颜色_ ：设置环境的光晕颜色

 _光晕强度_ ：设置环境的光晕强度，数值越高光晕越明显

 _天际线强度_ ：设置天空的天际线强度，数值越高天际线越明显

 _天空背景色_ ：可以调整天空的背景色，分为上下层向阳天空背景色、上下层背阳天空背景色

 _环境颜色_ ：可以调整环境的颜色，分为顶面颜色、侧面颜色、地面颜色

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhdznsie9up8/f38c6303-8822-4bd5-be7d-46da98bdd5ab.png)

支持配置颜色配置项可以通过选色器来调整颜色和透明度

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhdznsie9up8/21ac8582-bc8a-4e1a-89fc-1d7af4239869.png)

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhdznsie9up8/b4b93678-f7cb-4adb-a09c-431f6adbef60.png)

启用【随时间自动切换】时，可以查看该参数在对应时间点的配置值

### (4)环境要素

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhdznsie9up8/4cf2151c-9741-45fb-af9c-8b6208e5b669.png)

 _太阳_ ：默认开启，可以调整颜色、亮度、角度、运动轨迹倾斜角度和大小

 _月亮_ ：默认开启，可以调整颜色、亮度、角度、运动轨迹倾斜角度、大小和圆缺

 _星星_ ：启用后可设置密度、强度

 _银河_ ：启用后可设置强度、受光颜色

 _云_ ：启用后可设置云的类型高云、中云、低云、薄云以及对应的强度和受光颜色

## 2.光源配置

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhdznsie9up8/eae46558-d848-453c-b32b-5c885d3372f5.png)

### (1)光源配置的入口

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhdznsie9up8/db8c7caa-3888-4c05-b2d1-5313b7d46d44.png)

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhdznsie9up8/da1b6b3f-8961-4514-9650-08e1e920b844.png)



点击左上角系统菜单，点击【光源管理】可以打开光源管理工具

### (2)光源配置

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhdznsie9up8/90c1165e-8586-4247-b361-d46680ddf52b.png)

光源的参数设置：

 _归属文件_ ：指被哪些环境配置引用

 _位置、旋转_ ：控制其在场景中的位置、旋转。

 _光源类型_ ：目前可选点光源、聚光灯两种。

 _颜色_ ：照射在其他模型上时，模型显现的颜色变化

 _半径_ ：照射的半径

 _强度_ ：被照射的模型上，颜色或亮度变化的程度

 _生效范围_ ：角色进入该范围时，光源才会被加载，可用于性能优化。

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhdznsie9up8/70f476ab-3654-479e-8402-267f1dbceb58.png)

## 3.天气

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhdznsie9up8/3a4b40a3-883c-40cd-b274-27f03698c62b.png)

一份环境配置下可设置多份天气配置，可随环境配置一同启用

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhdznsie9up8/87fa78b8-5b13-437e-a9de-704afddfa1c4.png)

 _初始生效_ ：该份配置是否初始生效

 _天气类型_ ：当前仅支持配置雾

 _随时间自动切换_ ：如果启用，则该天气会随时间变换。如果不启用，则不会随着时间变换，而是保持当前配置的固定值

 _距离雾设置_ ：根据镜头位置，使远处的模型、天空显现被雾遮挡的效果。

 _高度雾设置_ ：根据场景高度，使远处的模型、天空显现被雾遮挡的效果。

# 三、环境时间

关卡设置中可定义游戏开始时的时间点，以及游戏中的时间流逝速度，也可以通过节点调整。

环境时间是全局唯一的运行值，无论各玩家应用的环境配置如何，服务器中将会持续地推进环境时间。仅有勾选“ _随时间自动切换_ ”的环境配置生效时，才会看到环境时间变换产生的效果变化

注意：关卡设置中的流逝时间配置为关卡运行中实际的流逝速度，而环境配置中的流逝时间配置为预览时的流逝速度，与关卡运行时无关
