# 概念介绍/高级概念/外围系统/奇匠订阅

(来源：原神千星奇域·综合指南，页面 ID mhzdzjixq98k)

# 一、奇匠订阅的定义

奇匠订阅功能是提供给创作者（奇匠）更方便建立流量私域，吸引粉丝游玩的功能，可以实时的将自己的发布/更新内容推送给订阅自己的粉丝玩家

# 二、发布订阅动态

在创作者（奇匠）发布/更新关卡时，将提示是否发布关卡动态，若勾选此项，则会向订阅自己的粉丝玩法发送动态

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhzdzjixq98k/2c24a44b-f71d-4527-aa28-9cd06f3eaea7.png)

单个创作者（奇匠）每周可发送3条动态，超出次数后本周不可发送，推送次数将在周一凌晨4：00刷新  
注意：删除动态/关卡不会返还推送次数

可在“人气奇域” — “订阅动态” — “我的动态”处管理所有已发布动态

# 三、局内订阅相关功能

## 1.局内订阅按钮  
![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhzdzjixq98k/ccbcd418-1b1a-43fa-a0b0-3b1f3d11eda1.png)

在界面控件组管理 —— 添加界面控件 —— 预制模板中新增订阅奇匠按钮，支持奇匠在局内界面中添加按钮吸引粉丝，按钮同样支持在悬浮交互页中添加，订阅按钮在试玩中同样生效

## 2.服务器节点-查询玩家是否订阅

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhzdzjixq98k/759fd0be-feba-4b6f-a87a-fe964bb30592.png)

新增查询节点，支持实时查询玩家是否为奇域创作者的订阅者，可用于配置粉丝福利等功能

查询创作者本人时节点默认输出“是”

# 四、奇匠订阅额外规则

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhzdzjixq98k/87c301cc-e579-40c9-8b67-ad2b32dede31.png)

随着奇匠经营的粉丝数、活跃度等数据越来越多，订阅按钮将发生额外变化，来作为人气奇匠的身份象征
