# 界面介绍/ID修改

(来源：原神千星奇域·综合指南，页面 ID mhsd6lrx3voe)

# 一、功能简介

ID修改系统给奇匠提供了在编辑过程中，可以动态修改和重新分配ID的功能，适用于实体GUID、元件ID、配置ID等所有包含ID引用的内容

# 二、功能入口

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhsd6lrx3voe/3de8f798-69bd-4e0f-bd63-95fcd6bd9879.png)

详情栏面板 → ID位置 → 复制功能后方

# 三、ID修改操作

点击 ID 修改按钮

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhsd6lrx3voe/865ea796-3ae4-49c6-b53e-5f786bf96202.png)

输入新的ID值后点击确认，即可成功修改ID

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhsd6lrx3voe/f37f0acc-c053-4373-901f-cd7ddb8ca199.png)

# 四、功能影响

## 1.引用关系

修改ID后，所有引用此对象的其他内容的引用关系会丢失

## 2.功能限制

部分功能无法修改ID，仅可查看或无法显示ID

## 3.检查内容

如果修改后的ID没有通过下述检测，则修改不会生效



输入ID是否与现有ID重复



输入为空



输入超过位数上限



是否归属当前业务类型

# 五、数据规则

## 1.ID组成结构

在编辑器中显示的ID为十进制，但实际我们实现时是将其转换为32位的二进制数来处理的，其中32位二进制位数对应的规则如下表

位数| 含义/规则  
---|---  
31位| 0  
30位| 1  
29位| 0  
22~28位| 下方的类型ID  
16~21位| 协作编辑部分的ID  
0~15位| 递增ID
