# 概念介绍/功能/通用组件/背包组件

(来源：原神千星奇域·综合指南，页面 ID mh5y5001vqd4)

#  一、背包组件的功能

背包组件将直接引用[背包](/ys/ugc/tutorial//detail/mhogfq9bf86q)模板，并在运行时生成对应的背包实例

背包组件仅支持同时选择一个背包模板

背包组件可以挂载在角色、造物、动态物件上

# 二、背包组件的编辑

## 1.添加组件

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mh5y5001vqd4/d639391b-44ca-4273-995b-c1560cc49a3a.png)

(1)在实体或元件编辑界面中，打开组件编辑页签

(2)点击下方的“添加组件”，选择并点击“背包”，成功添加

(3)点击“详细编辑”，展开编辑页

## 2.基础概念

通过组件添加可以为角色配置背包组件，并定义背包内的默认道具

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mh5y5001vqd4/a7fff02b-7409-463f-8b5d-b590d260c781.png)

 _背包模板_ ：引用一个背包模板

 _初始物品_ ：背包内默认拥有的物品配置，在玩法初始化时，会使角色默认携带这些物品
