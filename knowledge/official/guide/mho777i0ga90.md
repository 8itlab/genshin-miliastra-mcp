# 界面介绍/千星沙箱

(来源：原神千星奇域·综合指南，页面 ID mho777i0ga90)

# 一、千星沙箱入口

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mho777i0ga90/56f9e52e-bbe3-446d-ab3c-3fe16dbfbddc.png)



进入编辑时自动开启



手动关闭后可从系统菜单左下方打开千星沙箱

# 二、千星沙箱界面样式



左侧独立小窗为资源管理器



右侧独立大窗为节点图资源管理器



其中，多个页签存在时，可拖拽更换顺序或拉出创建子窗口

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mho777i0ga90/314703b0-50a1-45ef-bb2d-d04ad906a439.png)

# 三、资源管理器



用于展示当前局内已存在的实体、元件等资源

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mho777i0ga90/32329bd9-f2b3-4e38-9736-b47c1fa319b3.png)

# 四、服务器节点图资源管理器



千星沙箱开启时默认打开服务器节点图资源管理器



上半部分展示当前已创建的所有服务器节点图



下半部分展示当前可挂载服务器节点图的资源对象



服务器节点图管理器主要功能：



创建并管理实体节点图、状态节点图、职业节点图和道具节点图



可通过节点图外部资产进行服务器节点图的导入

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mho777i0ga90/e8e54833-fde6-4757-aea7-b39d2ad7bc44.png)



顶部菜单栏中可通过【窗口】子菜单打开：



资源管理器



客户端节点图资源管理器



节点管理器



日志



服务器信号管理器



负载检测

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mho777i0ga90/33e0e4ae-de4e-4ea3-aa9b-662980117ee9.png)

# 五、客户端节点图资源管理器



客户端节点图管理器主要功能：



创建并管理角色技能节点图、造物技能节点图、造物状态节点图、造物状态决策节点图和本地过滤器节点图。



本地过滤器包含布尔过滤器和整数过滤器两种类型



可通过节点图外部资产进行客户端节点图的导入

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mho777i0ga90/aea34c21-21e6-4665-801a-ec703f78e668.png)

# 六、节点管理器



节点管理器主要功能：



查看当前所有的节点分类及节点详情



创建并管理复合节点



可通过节点外部资产进行复合节点的导入

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mho777i0ga90/c10ea804-8754-4dd9-a8cb-326b678c4814.png)

# 七、日志



日志主要功能：



可选取指定的节点图，在关卡运行时实时记录该节点图的运行信息

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mho777i0ga90/ad0e6c62-fb5f-467e-9b2b-df91aa7aaa32.png)

# 八、服务器信号管理器



服务器信号主要功能：



可自定义信号参数，后续可使用对应的信号节点来实现信号的发送功能

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mho777i0ga90/26ebd739-faa8-46c8-abf5-2a1d07f5c0fd.png)

# 九、负载检测



负载检测主要功能：



可以检测并记录节点图在运行时产生的负载数据

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mho777i0ga90/3021b161-2250-4290-9cfd-bd67cb648c1a.png)
