# 界面介绍/试玩

(来源：原神千星奇域·综合指南，页面 ID mhie54ik9ovg)

# 一、功能简介

试玩功能可用于进行关卡测试，创作者(奇匠)可以通过试玩设置和试玩控制，满足自身对于不同情景的测试需求，以达到快速验证关卡的效果。

# 二、功能入口

系统菜单——试玩

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhie54ik9ovg/6e9fab45-86d6-4d41-8aaf-13a32ee5af09.png)

# 三、功能限制

多人试玩房间未解散时，无法进行试玩功能。

# 四、试玩校验

点击【试玩】按钮后，会执行试玩必要的校验和上传流程，当检测到未满足条件时，将弹出对应的错误码供创作者(奇匠)检查。当所有检测条件都通过时，试玩流程将继续进行，弹出【试玩设置】窗口。

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhie54ik9ovg/2bc047dd-9005-4f07-ab89-9227326cc0d7.png)

# 五、试玩流程

试玩流程分为：试玩前准备（上传，校验流程）——装扮展示——加载界面——进入关卡——结算关卡

## 1.试玩前准备

### (1)试玩玩家选取

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhie54ik9ovg/d4ee1a8a-0f8c-4fa2-85a0-d95ccd8fc774.png)

 _试玩时玩家编号_ ：点击后，将读取【关卡设置】中的已设定数据，可自由选择希望本次试玩的玩家对应编号。

### (2)存档数据设置

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhie54ik9ovg/d338fa0d-9ad5-48ca-ba6b-dce9f9e6149b.png)![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhie54ik9ovg/a3fe7222-721e-4276-b54b-80a97041cdad.png)

根据创作者(奇匠)需要，可通过系统菜单——试玩临时数据管理，进行存档数据的设置

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhie54ik9ovg/eabf063e-76a9-450f-9873-79ac49e0c049.png)

在试玩设置中可以将存档数据在【试玩数据】中进行引用。

## 2.装扮展示

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhie54ik9ovg/5295dd1c-fcbd-4cb0-a36d-804d0a676a80.png)

 _装扮展示阶段_ ：关闭后，试玩进入关卡时，将跳过装扮展示流程，直接进入加载界面。

## 3.结算关卡

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhie54ik9ovg/e4be6da2-8681-45fe-bb85-7ef4eb5f9e68.png)

玩家可通过完成挑战或者主动退出来触发关卡结算。

为了加快测试效率以及减少试玩测试中的流程，创作者(奇匠)可通过【试玩选项】中【启用试玩结算】关闭结算相关流程。

## 4.试用奇偶

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhie54ik9ovg/f1b13287-5bde-4644-a053-c6804bcd02bb.png)

创作者(奇匠)在进入试玩前，可通过【试玩选项】内【试用奇偶】调整试玩中使用的奇偶性别。

## 5.试玩时语言

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhie54ik9ovg/c9be4067-88c1-408b-8b08-6f6f2dbc1102.png)

创作者(奇匠)在进入试玩前，可以通过下拉框选择该次试玩时使用的语言，不需要再去设置里切换语言

## 6.加载界面

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhie54ik9ovg/3264390e-d3ac-48b7-82e6-5376b6ebe994.png)

执行完装扮展示后，试玩将依照【关卡设置】中【加载界面】的配置情况，播放进关前的加载界面。

## 7.进入关卡

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhie54ik9ovg/a4c75796-4017-4b0f-afb5-6395ccc1ce42.png)

点击按钮后，将根据创作者(奇匠)的设置依次执行进入关卡流程（装扮展示——加载界面——进入关卡）。

# 六、试玩局内控制

## 1.退出按钮

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhie54ik9ovg/e7a9c4a5-8948-4fb9-b84c-c6110286094a.png)

处于试玩中时，可通过左上角退出按钮或Esc快捷键打开【试玩控制】面板。

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhie54ik9ovg/0bb05341-baeb-4574-aaeb-406360e2bf4b.png)

## 2.试玩控制

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhie54ik9ovg/72b3d27e-f109-4941-9bae-4565415a3947.png)

### (1)继续挑战

点击【继续挑战】按钮后，将返回当前试玩进程

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhie54ik9ovg/02ef640c-a35f-4fa6-b356-cd597888aa48.png)

### (2)重新挑战

点击【重新挑战】按钮后，将重新执行从进关流程开始的所有启动流程，流程执行完后即重新开始新一局试玩。

注：如触发异常情况导致试玩无法直接重新开始，请退出试玩后重新开启试玩流程。

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhie54ik9ovg/45de9484-5b54-484a-abe2-01e1c8fe6327.png)

### (3)中断挑战

点击该按钮后，将立即结束本次试玩流程，触发对应的非正常结算结果。

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhie54ik9ovg/6383c777-7941-4228-880d-ac1c134a8b08.png)
