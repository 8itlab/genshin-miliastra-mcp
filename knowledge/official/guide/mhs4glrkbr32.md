# 概念介绍/单位/物件/白盒物件

(来源：原神千星奇域·综合指南，页面 ID mhs4glrkbr32)

# 一、什么是白盒物件

白盒物件是用于验证关卡设计的基础几何体集合

通过提供多种标准形状和材质显示模式，支持在编辑阶段进行空间验证和设计原型搭建，可正常当做一个模型资产使用，支持进行缩放、换色、换材质、挂载逻辑组件、挂载节点图等功能

# 二、白盒物件编辑入口

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhs4glrkbr32/c86e1924-fb63-4aba-9863-0019ca83a913.png)

在实体编辑页签的预制 —— 动态单位 —— 其他中可以找到白盒物件，将对应的物件拖入场景即可使用

# 三、白盒物件类型

支持以下标准白盒几何体：

长方体

球体

平面

三棱柱

五棱柱

三棱锥

五棱锥

圆柱

圆锥

线框长方体（常用于区域标注）

线框圆柱（常用于区域标注）
