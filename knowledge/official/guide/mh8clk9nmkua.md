# 概念介绍/高级概念/外围系统/先行体验

(来源：原神千星奇域·综合指南，页面 ID mh8clk9nmkua)

# 一、先行体验功能的定义

 _先行体验_ 功能是提供给创作者（奇匠）快速将关卡玩法原型上线测试，并用以告知玩家关卡处于待完善状态，并获得玩家即时反馈的功能。

发布 _先行体验_ 版本后，关卡的游玩数据、好评差评情况按照正常规则累积，奇匠可以保持更新，直到发布正式版本。

# 二、发布先行体验关卡

## 1.入口

在**首次发布关卡** ，编辑预览信息时，可以选择将该关作为“先行体验”版本进行发布（若不勾选，则会直接以正式版本发布）

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mh8clk9nmkua/b6c6d299-cecd-4d23-892a-746835874a09.png)

奇匠可以在下方【 _先行体验版本说明_ 】处填写说明文字

## 2.先行体验版本规则

当奇匠的关卡处于 _先行体验_ 状态时，发布的更新会显示为”X.xx先行体验版本“。发布正式版后，正式版更新计数会从1.01开始。

## 3.发布正式版本关卡

发布 _先行体验_ 后，再次发布关卡时，可以在相同入口处将关卡状态转为 _正式版本_

需要注意的是，确认发布 _正式版本_ 后，关卡无法再转回为 _先行体验_ 版本
