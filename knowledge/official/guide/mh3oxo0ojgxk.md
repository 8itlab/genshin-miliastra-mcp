# 概念介绍/功能/基础信息

(来源：原神千星奇域·综合指南，页面 ID mh3oxo0ojgxk)

_实体_ 的 _基础信息_ 是与实体模型和位置相关的特征或数据

在游戏过程中，基础信息可以被动态读取或修改，但不能被动态添加或删除

# 二、基础信息覆写

在制作元件时，可以指定该元件的基础信息，当把元件转化为实体布设在场景里时，会自动应用元件上编写的基础信息值，但是也支持在实体上重新改写基础信息，改写实体的基础信息时，元件的基础信息不会变化

# 三、基础信息的差异性

不同类型的元件，可用的基础信息也会有所差异
