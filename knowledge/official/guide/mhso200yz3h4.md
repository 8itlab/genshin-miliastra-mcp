# 概念介绍/功能/通用组件/光标碰撞盒

(来源：原神千星奇域·综合指南，页面 ID mhso200yz3h4)

# 一、光标碰撞盒组件的功能

光标碰撞盒可挂载于实体上，用于光标射线的碰撞检测

# 二、光标碰撞盒组件的编辑

## **1.添加组** 件

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhso200yz3h4/dd19f8d9-0846-420b-b9d2-44e24003d20a.png)

(1)在实体/元件编辑界面中，打开组件编辑页签

(2)点击下方的“添加通用组件”，选择并点击“光标碰撞盒”，成功添加

(3)点击“详细编辑”，展开编辑页

## **2.光标碰撞盒组** 件的编辑

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhso200yz3h4/64c776ec-71ad-4111-ae3e-6c64d752b5ec.png)

配置参数| 说明  
---|---  
 _初始生效光标碰撞_|  下拉菜单提供光标碰撞盒枚举通过修改后面的勾选框，可以修改生效情况，修改后生效状态会同步到寻路阻挡编辑页内![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhso200yz3h4/9bb20840-3b1d-41fc-aea1-2007069bc2b0.png)![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhso200yz3h4/d485aeb4-a810-48e0-8ff9-5d063ba15ec7.png)  
 _*光标碰撞体列表_|  枚举实体配置的所有光标碰撞体  
  
# **三、** 光标碰撞盒**的编** 辑

## 1\. **添加** 光标碰撞

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhso200yz3h4/391e6705-1b21-45cf-8705-f82abbe3546e.png)



通过点击![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhso200yz3h4/1e95a6d9-6080-4cfe-bad1-7f62722ab211.png)，添加光标碰撞
