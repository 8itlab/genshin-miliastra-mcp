# 概念介绍/功能/通用组件/物件镜头

(来源：原神千星奇域·综合指南，页面 ID mhx9b60or59k)

# 一、物件镜头组件的功能

通过组件的形式允许动态物件/造物挂载额外镜头，可以在关卡运行中切换镜头以增加更好的表现效果

# 二、物件镜头组件的编辑

## **1.添加组** 件

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhx9b60or59k/74f38d2e-ccf8-49aa-b8dc-b0c21795bee0.png)

(1)在实体/元件编辑界面中，打开组件编辑页签

(2)点击下方的“添加通用组件”，选择并点击“物件镜头”，成功添加

(3)点击“详细编辑”，展开编辑页

## **2.物件镜头组** 件的编辑

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhx9b60or59k/607a3ea5-ff32-4ecd-a7e3-c8d966ca8715.png)

点击+新建物件镜头，通过选择镜头可选择预先配置好的物件镜头模板

可通过【管理镜头】进入【主镜头管理】对镜头进行编辑

选中镜头后，可以通过【进入预览模式】来预览当前镜头

![](https://act-webstatic.mihoyo.com/ugc-tutorial/knowledge/cn/zh-cn/mhx9b60or59k/948317fe-ae61-448a-801a-3645d913f7ef.png)
