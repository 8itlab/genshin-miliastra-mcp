# 新手入门系列视频教程/建成我的第一个奇域/组件设置：特效（视频文字稿）

## 全文

我们接着来制作奇域中使用特效的元件。目标是制作一个可以点燃的火炬,在玩法机关中找到元素火炬。为其添加一个选项卡的组件。点击详细编辑,可以修改选项卡图标,修改选项卡的名字为点燃。点击触发选项区域中心外轴质改为1,缩放倍率都改为2。我们为其添加一个节点图,使得点击选项卡时播放点燃的特效。打开千星沙箱右键创建节点图,修改节点图名称为点燃火炬。当选项卡选中时播放特效,随后关闭选项卡。目标实体即为事件原实体,也就是火炬本身。位置偏移外轴纸设置为1.2。保存节点图,将节点图挂载在火炬上。保存元件,命名为火炬。将元件放置在物件摆放界面。点击试完查看效果。这样,我们就制作好了特效的相关元件。
