# 新手入门系列视频教程/制作我的第一个奇域组件/交互界面的搭建（视频文字稿）

(来源：原神千星奇域·教程，页面 ID mhxekxruo6ym；视频 https://act-webstatic.mihoyo.com/ugc-tutorial/course/cn/zh-cn/mhxekxruo6ym/7c835546-4600-489a-9d04-b2985e454de8.mp4)

## 全文

紧接着,我们需要制作一个可以显示积分值变化的交互界面。点击左上角的自定义页面签,打开界面控建组管理,点击界面控建组库,添加界面控建模板,选择文本框。修改文本内容为目标积分,5,现积分。插入变量,点击玩家自身,选择积分值。修改文本框的位置和大小,最后我们点击另存为模板。打开界面布局,点击添加界面控建,将制作好的文本框添加到界面中。此时,一个可以显示积分值变化的交互界面就做好了。
