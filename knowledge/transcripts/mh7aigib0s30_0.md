# 新手入门系列视频教程/建成我的第一个奇域/玩法整合：关卡试玩（视频文字稿）

(来源：原神千星奇域·教程，页面 ID mh7aigib0s30；视频 https://act-webstatic.mihoyo.com/ugc-tutorial/course/cn/zh-cn/mh7aigib0s30/9facf63c-c700-4925-b0d0-027844e40828.mp4)

## 全文

奇域制作完成,让我们开始试玩游戏吧!回到千星奇域,点击左上角的自定义页面签,点击试玩。进入奇域后,首先看到的是通关规则弹窗。关闭弹窗,拾取金币后,积分会增加。在奇域的第一关,我们乘坐电梯到达上方平台。第二关中,点击交互装置的选项卡,石板就会全部上升。进入石板1.5秒后,石板会坍塌,所以我们得快速通过石桥。接着,我们来到第三关,会出现寻找武器的提示信息。点燃四个火炬,解锁武器。拾取地上的武器后,我们将获得战斗能力。此刻,会出现一个敌人,消灭敌人后等级提升到40级。继续前进,通过移动的平台到达对岸。消灭敌人后等级提升到90级。最后一关,我们继续向前对抗中级boss。消灭boss后,打开宝箱,获得钥匙。来到大门前,出现提示,大门需钥匙开启。用钥匙打开大门,收集剩余的金币。达到目标积分后,退出奇遇装置启动。触发烟花特效,选择退出奇遇,显示胜利的动画。试玩顺畅,奇遇搭建成功。试玩顺畅。
