# 新手入门系列视频教程/建成我的第一个奇域/组件设置：技能与职业（视频文字稿）

(来源：原神千星奇域·教程，页面 ID mhgk8b99qiuy；视频 https://act-webstatic.mihoyo.com/ugc-tutorial/course/cn/zh-cn/mhgk8b99qiuy/b63064bb-0361-4ca0-be83-81c812c2e02a.mp4)

## 全文

接着,我们制作一个可失去的武器。在其他中找到空模型。为其添加一个碰撞触发器的组件。点击详细编辑,添加一个触发器,打开初始生效。生效目标,选择角色。中心外轴值改为0.5,缩放倍率都改为1.5。在组件列表中找到特效播放,点击详细编辑,点击添加特效。特效资产类型选择循环特效。为其添加一个单手键01特效,偏移外轴值设置为0.7,旋转X轴值设置为90。点击播放按钮查看效果,关闭元件的原生碰撞。保存元件,修改名称为武器。这样一个可拾取的武器就做好了。我们再制作一个可以战斗的职业。玩家拾取武器后,通过切换职业来实现可以战斗的功能。进入战斗预设界面,找到职业,点击新建职业,修改职业名为现实。将基础生命值设为100。属性成长设置为默认成长曲线。打开右侧面板的技能模块,点击加号添加技能。选择之前导入的技能普通攻击。这样,一个拥有战斗技能的职业就制作好了。我们为武器元件添加一个可以切换职业的节点图,打开千辛沙香,右键创作节点图,修改节点图名称为获得战斗能力。当进入碰撞触发器时,更改玩家的职业,目标职业为现实职业的ID。目标玩家需要通过获取角色归属的玩家实体节点来获取。玩家职业更改后,将单手间特效挂载到角色右手上。目标实体就是进入者实体即角色。接着,销毁武器实体。目标实体为触发器实体即武器。保存节点图,将节点图挂载在武器上。覆盖保存元件。将元件放置在物件摆放界面。点击试玩,查看效果。这样,玩家的职业和技能就制作好了。
