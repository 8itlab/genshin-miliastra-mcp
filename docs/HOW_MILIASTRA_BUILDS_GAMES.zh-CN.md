# 千星奇域是怎么搭游戏的

整理自官方综合指南（219 页）、教程（84 页）和 48 份官方教学存档的拆解，2026-10-10。原文都在 `knowledge/`，用 `search_knowledge` 能搜到；本文只讲骨架：平台给了哪些积木、官方自己怎么拼、我们的工具覆盖到哪。标 ✅ 的是我们实测过的，标 📖 的只来自官方资料、还没在游戏里验证。

## 一、心智模型：五种单位、四个面板

**单位 → 元件 → 实体。** 元件是预设的数据（像类），实体是场景里或运行时的具体一份（像对象）。摆在场景里的实体有全局唯一的 GUID；运行时用【创建元件】按元件 ID 生出来的实体 GUID 为 0。只有动态物件元件和造物元件能在运行时创建。📖

单位有六种，各有各的职责：

| 单位 | 是什么 | 能挂什么 | 典型用途 |
|---|---|---|---|
| **玩家** | 纯逻辑实体，没有模型；超限模式一个玩家对应一个角色。配置走"玩家模板" | 自定义变量、全局计时器、单位状态；节点图 | 记这个玩家的积分、拿着什么工具、当前选中了哪块地 |
| **角色** | 玩家操控的那个人，属性和技能主要由**职业**决定 | 自定义变量、单位状态、铭牌、小地图标识、自定义挂接点；节点图 | 响应技能（客户端技能图→服务器"技能节点调用时"）、加减技能 |
| **造物** | 怪、小动物、机械等，会对敌对阵营自主反应。行为模式编辑时选定、运行时不能换 | 选项卡、碰撞触发器、自定义变量、全局计时器、单位状态、特效播放、自定义挂接点、碰撞触发源、音效、背包、战利品、铭牌、文本气泡、商店、扫描标签、小地图标识；节点图 | 敌人、NPC 商人、可交互的伙伴 |
| **物件** | 地貌、建筑、机关的统称；自己不会动，装运动器才动。分**静态**（纯摆设，不能挂任何功能）和**动态**（有预设状态、组件、节点图） | 全部通用组件；节点图 | 机关、门、拾取物、触发区、金币 |
| **本地投射物** | 客户端的子弹 | — | 技能投射物 |
| **关卡** | 每张图自带一个，纯逻辑，只有位置。**物件和造物被销毁时的事件只会发到关卡实体上** | 自定义变量、全局计时器；节点图 | 全局计时、结算、统计"怪死了几只" |

每个动态实体/元件都有四个面板：**基础信息**（变换、模型、碰撞、可见性、创建设置、阵营、单位标签、负载优化）、**特化配置**（战斗属性、仇恨、受击盒、战斗设置、能力单元）、**通用组件**、**节点图**。功能靠"加组件"获得，逻辑靠"挂节点图"实现。

**两种模式**：超限模式（奇偶角色、一切可自定义、最多 8 人）和经典模式（带提瓦特角色进来、最多 4 人、没有职业/角色技能/自定义仇恨/负载优化/护盾等）。我们一直在做超限模式。

## 二、系统清单：平台已经给了什么

### 通用组件（加在实体上）

| 组件 | 上表二十多种 | ✅ 碰撞触发器、选项卡、自定义变量（`scene_add_components`，写出的记录和官方存档逐字节相同，游戏内验证过） | 商店、掉落物、背包、铭牌、文本气泡、运动器还没做；它们的编码已在 `knowledge/notes/component-codes.zh-CN.md` |
|---|---|---|
| **碰撞触发器** / 碰撞触发源 | 一块检测范围，带"碰撞触发源"的实体（角色默认带）进入/离开时发事件；可配生效目标（角色/物件/造物）、形状、缩放、初始是否生效 | 事件【进入碰撞触发器时】【离开碰撞触发器时】；【激活/关闭触发器】。**官方样例里第二常用的事件（43 次）** |
| **选项卡** | 原神原生的"靠近出现交互选项"：进入范围弹选项列表，可多个选项、图标、排序、本地过滤器决定是否显示 | 事件【选项卡选中时】带选项序号；【激活/关闭选项卡】。**官方样例里最常用的事件（49 次）**——付款、拾取、开箱、拉杆全是它 |
| **自定义变量** | 实体身上的键值存储，强类型，支持列表/字典/结构体；所有单位默认带 | 【设置自定义变量】（可选触发事件）【获取自定义变量】、事件【自定义变量变化时】（带变量名、前值、后值）。读写是全局的，事件只发给挂图的那个实体 |
| **定时器** | 只能由节点图创建，归属某实体，序列 [1,3,5,7] 秒各触发一次，可循环，最小间隔 0.03 s | 【启动/暂停/恢复/终止定时器】、事件【定时器触发时】带序号 |
| **全局计时器** | 关卡级的计时/倒计时，可同步到界面控件显示 | 【全局计时器触发时】等 |
| **单位状态** | 增益/减益（属性加成、描边、透视、无敌…），有官方状态池 | 【添加/移除单位状态】 |
| **基础运动器** / 跟随运动器 / 投射运动器 / 操控运动器 | 让物件按轨迹动、跟着某实体动、像子弹飞、被玩家操控（载具） | 【激活基础运动器】【切换跟随目标】… |
| **特效播放** / 音效播放器 | 挂循环特效、放限时特效、放音效 | 【挂载循环特效】【播放限时特效】 |
| **铭牌** | 头顶名字、血条、状态、导航指示器 | 【设置铭牌…】 |
| **文本气泡** | 头顶对话气泡 | 【显示文本气泡】 |
| **背包组件** / 战利品 / 商店组件 | 背包按模板；战利品是死亡掉落；商店按"商店模板"买卖 | 【打开商店】【添加道具】… |
| **命中检测** / 额外碰撞 / 受击盒 | 攻击命中判定 | 事件【命中检测触发时】 |
| **自定义挂接点** | 实体上的命名位置，可跟随旋转，给创建/特效用 | 【查询挂接点位置】 |
| **小地图标识** / 扫描标签 / 光源 / 寻路阻挡 / 物件镜头 / 光标碰撞盒 | 字面意思 | — |

### 关卡级系统（ESC 菜单 / 战斗预设里配）

| 系统 | 管什么 |
|---|---|
| **关卡设置** | 场景生效范围、环境等级、人数分组、时间流逝比例、负载优化、**仇恨类型（默认/自定义）**、阵营、出生点、复苏点、加载界面、**结算界面类型（个人/阵营）和游戏内排名**、地形导航烘焙 |
| **阵营** | 玩家 1 / 物件 2 / 造物 3 默认两两敌对；可加阵营、设友善/敌对名单。玩法分队就是分阵营 ✅ |
| **预设点** | 带名字和索引的位置+朝向，出生点、复苏点、节点图【查询预设点位置旋转】都引用它；可打单位标签批量取 |
| **职业** | 一整套打包：镜头模板、主屏布局、能不能跳/冲/爬/滑翔、等级和成长曲线、基础战斗属性、仇恨倍率、单位状态、抗打断、**技能槽**、职业组件、职业节点图。玩家切职业时整套覆写一次 |
| **技能** | 客户端技能节点图（有"节点图开始"节点，不是事件驱动）；本地技能没有实际效果，靠【通知服务器节点图】让角色上的服务器图处理（事件【技能节点调用时】）。角色技能用【添加技能】【以槽位删除角色技能】运行时增减 |
| **道具 / 装备 / 货币 / 背包 / 掉落物 / 商店** | 一条完整的资源链：道具有品质和货币价值；货币在"货币与背包"里定义，可配销毁时保留；掉落物是带【掉落物组件】的实体，拾取规则可交互/自动；商店模板配出售表和收购表；背包模板配格子 |
| **界面控件** | 近 30 种：文本框、进度条、计时器、计分板、弹窗、卡牌选择器、自定义按钮/开关、图片、状态显示区、消息队列、小地图、网格视窗……在"界面布局"里摆，节点图用【设置界面控件状态】改值、事件【界面控件组触发时】收按钮 |
| **关卡结算** | 节点【结算关卡】结束整局；之前用【设置玩家/阵营结算成功状态】（胜利/失败/未定）和【设置…排名数值】；结算界面样式在关卡设置里选 |
| **信号** | 全局自定义结构（名字+任意参数），任意服务器图【发送信号】、任意服务器图【接收信号】；技能图也能向服务器发 |
| **环境配置** | 天空、滤镜、光源、天气、环境时间，可建多套、节点图【切换环境配置】 |
| **主镜头** | 镜头模板（距离、俯仰、视野、跟随），职业指定默认模板，节点图切换 |
| **场景生成模板** | 按范围/密度/权重随机铺植被岩石 |
| **元件组** | 把一组摆好的东西打包成一个元件 |
| **局内存档 / 多语言 / 排行榜 / 段位 / 成就 / 礼盒 / 任务** | 外围系统 |

### 节点图

- 七种图：实体、状态、职业、道具（服务端）；布尔过滤器、整数过滤器、技能（客户端）。
- 服务端图**全部事件驱动**：每条逻辑子图从一个事件节点开始；"事件源实体"就是挂图的那个实体。
- 强类型；字符串最长 40 个英文字符；列表/字典按引用传递，改了不触发变量变化事件。
- 运算流跟着执行流求值，每个执行节点各算一次（随机数会因此不同）。
- 节点图变量、复合节点、字典、结构体、日志打印是附录里的高级特性。

## 三、官方是怎么拼的（从 48 份教学存档里看出来的）

1. **一个玩法 = 很多张小图，各挂各的实体。** 《农场乱斗》玩法流程：22 个实体、18 张图、284 个节点；最大的一张（角色-使用/放下工具）53 个节点。"建成我的第一个奇域"：314 个实体、18 张图、124 个节点。图按"谁-做什么"命名：`物件-种植格-可操作`、`玩家-拾取工具`、`角色-使用/放下工具`、`关卡-游戏结束传送`。
2. **图挂在当事的实体上，元件一改全体生效。** 金币的图挂在每一个金币上（30 个金币共一张图）；玩家的图挂在玩家模板（9 个玩家位各一份）；角色的图挂在角色模板；关卡实体只挂"实体被销毁""全局计时器"这类别人收不到的事件。
3. **状态放在当事实体的自定义变量上。** 玩家身上：是否有工具、拿的是什么、积分、采集数；土地身上：等级、是否可采集、上面种的植物（实体型变量）。要让别的图知道，就在设置变量时勾"触发事件"，别的图用【自定义变量变化时】接。
4. **交互靠两种组件，不靠坐标判断。** 要"走到就触发"用碰撞触发器；要"走到后按键确认"用选项卡。付款、拾取、开门、切换职业、开始游戏、结算，样例里全是这两个事件。
5. **跨实体通知用信号。** 机关触发→发信号→门自己开、火把自己点、角色自己加技能；要新增"丘丘人改变量"只改丘丘人的图。
6. **玩家输入走技能。** 拿起工具 = 给角色【添加技能】"使用工具"和"放下"，技能图里只做【通知服务器节点图】，角色上的服务器图用【技能节点调用时】按技能参数分支。
7. **表现变化靠销毁重建或预设状态。** 土地升级 = 在原位【创建元件】另一个元件；宝箱开 = 【设置预设状态】；种子成熟 = 换元件 + 挂循环特效。
8. **时间靠定时器序列，不靠自己数帧。** 植物每 2 秒长一级 = 在土地上【启动定时器】[2,4,6]，【定时器触发时】按序号分支。
9. **最常用的节点**（48 份样例统计）：获取自身实体 153、获取角色所属玩家 90、双分支 78、创建元件 72、设置自定义变量 62+37+29+17、多分支 44+34、销毁实体 42、按 GUID 查实体 35、设置预设状态 25、挂载循环特效 24、启动定时器 22、激活/关闭选项卡 20、添加/删除角色技能 12+12、结算关卡 10。

## 四、我们的工具覆盖到哪

| 层 | 平台能力 | 我们现在（2026-10-11 上午；✅ 都是在游戏里验证过的） | 差距 |
|---|---|---|---|
| 场景 | 摆物件、缩放、元件、元件组、场景生成模板 | ✅ `scene_build_blocks` / `scene_import_assets` / `scene_add_prefab`（物件、造物、掉落物三种元件，可带预设状态、生命值）/ 图鉴 | 元件组、场景生成模板没有 |
| 单位 | 玩家模板、角色模板、职业、造物行为模式 | ✅ 出生点和预设点（`scene_set_spawn`、`scene_add_preset_point`）；职业的跳跃、攀爬、冲刺、滑翔开关和镜头（`scene_set_class`）；造物元件由图创建后会自己行动 | 新建职业、属性和等级 |
| 组件 | 二十多种 | ✅ 碰撞触发器、选项卡（含布尔过滤器）、自定义变量、基础运动器（直线、路径）、跟随运动器、小地图标识、受击盒、能力单元（直接攻击）、战利品、投射运动器、命中检测，都在 `scene_add_components`；商店在 `scene_add_shop`；背包随 `scene_add_currency` | 铭牌、文本气泡、扰动装置、挂接点没做；编码在 `knowledge/notes/component-codes.zh-CN.md` |
| 节点图 | 七种图，挂在任意实体 | ✅ 服务器实体图挂关卡实体、任意元件（一张图可挂多个元件）、玩家模板、角色模板；✅ 道具节点图；✅ 客户端的角色技能图和布尔过滤器图 | 造物技能、造物状态、造物决策三种客户端图没接到造物上 |
| 变量 | 实体上的自定义变量 + 变化事件 | ✅ 整数、布尔、浮点、字符串的默认变量 | 列表、字典、结构体类型的默认值没做 |
| 关卡设置 | 仇恨类型、负载档、阵营关系、出生点、结算 | ✅ 仇恨类型、负载档、阵营敌对、镜头、出生点；结算走节点（胜、负都进官方结算界面） | 结算样式、人数分组没有 |
| 资源链 | 道具、货币、背包、商店、掉落物 | ✅ 货币（`scene_add_currency`）、道具（`scene_add_item`）、商店（`scene_add_shop`，平台自带的买卖界面）、掉落物（`scene_add_prefab` 的 `drop`）、战利品（`scene_add_components` 的 `loot`）、可使用的道具（消耗品 + 道具节点图） | 装备、背包商店那一种没做 |
| 技能 | 瞬发、普通、长按、连段、瞄准 | ✅ 瞬发和普通（一段动画、可在某一毫秒触发、可挂武器）；✅ 技能图里打攻击盒，能打到怪和带受击盒的物件 | 长按、连段、瞄准、冷却和次数没做 |
| 界面 | 近 30 种控件 + 布局 | ✅ 进度条、计时器、交互按钮（`scene_add_progress_bar`、`scene_add_timer_display`、`scene_add_button`） | 计分板、图片等没做；文本框在奇匠 Lv.1 账号下不显示（实测） |
| 表现 | 环境、光源、单位状态、预设状态、特效 | ✅ 环境配置和光源（昼夜靠两套配置切换）、描边状态、45 个机关物件的预设状态；图里放特效、音效、换背景音乐，三样的名字和编号都能查（`effect_catalog`、`sound_catalog`、`music_catalog`）；试玩能录音核对；复杂造物的决策图、状态图、技能（`scene_add_creature_skill`、`scene_set_creature_logic`，`examples/brain`） | 滤镜、天气、其它种类的单位状态 |
| 信号 / 计时 | 全局广播、全局计时器 | ✅ 信号（可带一个字符串参数）、全局计时器 | 其它类型和多个参数的信号 |
| 试玩 | 试玩、日志、结算 | ✅ 一键试玩、日志、截图、服务器消息；脚本能按键、点鼠标、点屏幕上的字、读屏幕文字 | — |

用这些工具从零搭出、并在游戏里按脚本走通的样例见 `examples/`：四个游戏（`kingdom4` 塔防经营、`hop` 平台跳跃、`farm` 采集经营、`raid` 打怪—战利品—买卖）和几个单项的验证关（`events`、`checks`、`skills`、`shop`、`drops`、`buttons`、`strike`、`shoot`、`potion`、`presets`）。

## 五、王国样例对照：哪些是野路子

| 王国现在的做法 | 官方的做法 | 代价 |
|---|---|---|
| 关卡实体上一张 1028 节点的图，每 0.2 秒把 12 只怪、12 个币、君主坐标全查一遍 | 每个东西挂自己的小图，事件触发 | 撞上运行负载上限（每秒 1400），节点数逼近 3000，人没法在编辑器里改 |
| 君主站在某坐标 2 秒 = 付款 | 站点元件挂**选项卡**（"招募 1 币"），【选项卡选中时】扣币 | 测试脚本时差导致连买两次，只好加"每次只成交一次" |
| 钱袋 = 脚边一排缩放的徽章元件；头顶金币 = 方块 | 金币是**货币**，钱包在**背包**，屏幕角落用**界面控件**显示数字 | 没有数字、没有提示 |
